## 📖 Descripción General

`web-apps-utilities` consolida **prototipos funcionales de aplicaciones web**, desde SPAs didácticas en Angular hasta aplicaciones de gestión de candidatos HR, trackers de tareas en React y versiones históricas del portafolio interactivo.

Cada app reside en `apps/[nombre]/` con su propio `README.md`, instrucciones de ejecución y demo visual.

## ⚡ Inicio Rápido

```bash
# Clonar el repositorio
git clone https://github.com/yefcode/web-apps-utilities.git
cd web-apps-utilities

# Instalar y ejecutar una app específica (ej: candidates-hr-manager)
cd apps/candidates-hr-manager
npm install
npm start
```
